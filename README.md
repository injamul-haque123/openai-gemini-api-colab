# OpenAI + Google Gemini API Demo

A Google Colab-ready Python example for calling OpenAI and Google Gemini models.

## Run in Google Colab

1. Open `AI_API_Demo.ipynb` in Colab.
2. Open **Secrets** (key icon).
3. Add:
   - `OPENAI_API_KEY`
   - `GEMINI_API_KEY`
4. Run the notebook cells.

Never commit API keys to GitHub.

## Open in Colab

Replace `USERNAME` and `REPOSITORY`:

https://colab.research.google.com/github/USERNAME/REPOSITORY/blob/main/AI_API_Demo.ipynb
